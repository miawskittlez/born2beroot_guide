# Cheat sheet: vim and nano

| Editor | How to |
|---|---|
| vim - edit | Press `i` to enter insert mode (`-- INSERT --` appears). Type your changes. |
| vim - leave insert mode | Press `Esc`. |
| vim - save and quit | `Esc`, then type `:wq` and Enter. |
| vim - quit without saving | `Esc`, then `:q!` and Enter. |
| vim - search | `/word` then Enter (for example `/Port`). |
| nano - save | `Ctrl+O`, then Enter. |
| nano - exit | `Ctrl+X`. |
| Installer menus | Arrows to move, Enter to select, Space to tick, Tab to reach buttons. |

Good luck, and remember: the point of the project is to understand what you built.
