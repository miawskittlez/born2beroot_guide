# Cheat sheet: vim and nano

| Action | Keys |
|---|---|
| vim: edit | `i` |
| vim: leave edit mode | `Esc` |
| vim: save and quit | `Esc`, then `:wq` and Enter |
| vim: quit without saving | `Esc`, then `:q!` and Enter |
| vim: search | `/word` and Enter |
| nano: save | `Ctrl+O`, Enter |
| nano: exit | `Ctrl+X` |
